# Requirements
## 背景と目的
現状，物件を探すときは以下のように情報収集している．
1. 物件サイトでフィルタ検索
2. 出てきた物件名をgoogleマップで検索
3. タグ付けしてメモ欄に家賃を記入
4. 通勤ルートを検索
5. 駅までのルートを検索
6. 周辺施設（コンビニ，スーパー，飲食店）を検索

困りごとは，以下の3点．本アプリは，以下の解消を目的とする．
1. 保存リストから物件タグを選択しないとマップに表示されず，面倒．
2. メモ欄が見たいだけだが，ノイズが多い．
3. 上記の4~6を物件ごとに行うのが面倒．また，検索結果を残せないので，忘れたら再度調べる必要がある．

## 必要機能
### REQ-001: 物件情報の登録
#### 受け入れ条件
ACC-001-01: 入力フォームから，以下の情報をアプリに登録できる．
- 物件の住所
- 物件の家賃
- 物件サイトのURL 

ACC-001-02: 物件の住所が入力されていない場合はアプリに登録できない．\
ACC-001-03: 物件の家賃が入力されていない場合はアプリに登録できない．\
ACC-001-04: 物件サイトのURLが入力されていない場合はアプリに登録できない．

### REQ-002: 物件情報の表示
#### 受け入れ条件
ACC-002-01: マップ上に，登録された全物件がピンで表示される．\
ACC-002-02: マップ上に表示されたピンをタップすると，登録された家賃とサイトURLが表示される．\
ACC-002-03: 表示されたサイトURLをタップすると，リンク先に遷移できる．

### REQ-003: 物件情報の削除
#### 受け入れ条件
ACC-003-01: マップ上に表示されたピンをタップすると，削除ボタンが表示される．\
ACC-003-02: 表示された削除ボタンをタップすると，物件情報をアプリから削除できる. \
